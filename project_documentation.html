Core Technologies & System Architecture

Languages & Frameworks

  • React.js + Vite: Core frontend framework for the Single Page Application (SPA).
  • Tailwind CSS: Rapid UI styling and responsive design.
  • Firebase Ecosystem: Firestore (NoSQL database), Authentication (Login sessions), Hosting (Production build), Storage (Media & Avatars).
  • Vite PWA: Powers offline capabilities and install-to-homescreen functionality via Workbox.
  • jsPDF & html2canvas: For automated dynamic PDF document generation.

Structural Integrity & Strategy

The system utilizes a central orchestrator approach. The App.jsx file acts as the "Brain", fetching all data collections via a massive Promise.all execution upon login. This ensures all modules (HR, CRM, POS, Accounting) have instant, synchronous access to data without loading spinners when switching tabs.

It relies heavily on Multi-tenancy (data is strictly isolated by Organization IDs) and Role-Based Access Control (RBAC), restricting views based on employee roles and branch assignments.

Local Setup & Deployment Guide

Local Development Setup

# 1. Clone the repository

git clone https://github.com/augustinejohnson/recloud-erp.git

cd recloud-erp

# 2. Install dependencies

npm install

# 3. Start development server

npm run dev

Deployment to Firebase

Recloud ERP is hosted on Firebase Hosting. Ensure you have the Firebase CLI installed (`npm i -g firebase-tools`) and are logged in via `firebase login`.

# 1. Build the production bundle

npm run build

# 2. Deploy to live

firebase deploy --only hosting

Project Milestones & Completed Stages (Detailed)

Stage 1: Foundation, Admin, & Human Resources

Completed

Transitioning from the legacy G4mg-Adamz logic to a scalable cloud ecosystem. Built the structural backbone for users, permissions, and organization data.

Module Features

  • Global Authentication: Login screen validating Organization ID and Employee credentials.
  • Employee Directory: Full roster management, role assignments (Admin, Manager, Cashier, Sales), and avatar generation.
  • Branch/Location Management: Create distinct store locations to bind employees and stock to specific physical places.
  • Payroll System: Salary settings, automated Payslip generation (PDF), and net pay tracking.
  • Recruitment System (ATS): Public-facing careers page and applicant tracking system pipeline (Applied -> Interview -> Hired).
  • Employee Self-Service (ESS): Restricted portal for non-admin staff to view payslips, request time-off, and check in for attendance.

Challenges & Resolutions

  • Challenge: Employees needed access to only their specific store's data.
  • Resolution: Implemented a warehouseId variable in the employee profile. All subsequent queries check if a user is an Admin; if not, it strictly filters data to match their warehouseId.

Stage 1.5: CRM (Customer Relationship Management)

Completed

Developed a robust client tracking and sales pipeline system for B2B and retail tracking.

Module Features

  • Customer Database: Add, edit, and track customer contact information globally.
  • Deals Pipeline: Kanban-style drag-and-drop board (Lead -> Negotiation -> Won -> Lost).
  • Activity Logging & Tasks: Log calls, emails, meetings, and create follow-up tasks with due dates.
  • Stuck Deal Alerts: Deals inactive for > 7 days flag visually to prevent lost revenue.
  • Invoicing: Generate and track invoices, log payment statuses, and print standard A4 PDF invoices linked directly to profiles.

Challenges & Resolutions

  • Challenge: Integrating CRM with POS later in the build.
  • Resolution: Structured the customers Firestore collection so that the POS module can read directly from the CRM, allowing cashiers to select existing CRM clients at checkout instantly.

Stage 2: Point of Sale (POS) & Inventory Control

Completed

The most complex phase: handling live financial transactions, stock deductions, and cashier workflows.

Inventory Features

  • Product Catalog: Categorization (e.g., Pharmaceuticals, Beverages) with image support.
  • Supplier Network & LPOs: Database of suppliers assigned to branches. Generate formal Purchase Orders (PDFs) to restock.
  • Stock Distribution: Track inventory levels uniquely per warehouse branch.
  • B2B Wholesale Portal: Dedicated routing system for distributors to log in and place bulk orders within credit limits.

POS Features

  • Fast Checkout UI: Image grid, category filters, and smart search bar. Fully mobile-responsive cart.
  • Hold System: Pause a transaction queue and start a new one if a customer is delayed.
  • Taxes, Discounts, Split Payments: Manual percentage input per transaction. Supports combined card/cash checkout.
  • Receipt Engine: Downloads an 80mm/58mm thermal-printer ready PDF on sale completion.
  • Shift Management (Best Practice): Cashiers must declare opening floats (cash in drawer) at the start of shifts and generate Z-reports (Expected vs Actual counts) at shift end to combat fraud.
  • Global Barcode Listeners: Implemented global window listeners to instantly capture 1D/2D USB barcode scanner inputs without requiring focus on a specific input field, intelligently ignoring typing.

Challenges, Questions & Solutions

  • Q: Can customer names be detected directly from ATM cards?
    Web applications cannot natively read encrypted physical card chips. Solution: We built a Dual-Flow system. We provided a manual button for traditional bank POS machines, and a "Sync Smart Terminal" button to interface with API-enabled machines (like Paystack Terminal) for automated data retrieval.
  • Challenge: Stock Race Conditions during checkout.
    Solution: Utilized Firebase writeBatch. A sale record and a stock deduction happen atomically. If the stock deduction fails, the sale cancels, ensuring inventory levels are never compromised.

Stage 3: Accounting, Reports & Operational Backbone

Completed

The financial core and analytics engines that tie all operations together into actionable insights and ledgers.

Accounting Module Features

  • General Ledger: Intercepts all transactions from the POS and Invoices automatically.
  • Profit & Loss Reporting: Generates real-time financial health reports.
  • Expense Tracking: Complete ledger for outgoings.
  • Chart of Accounts: Fully featured categorization of assets, liabilities, and equities.

Analytics & Specialized Operations

  • Advanced Reports Dashboard: Converts raw sales, CRM, and HR data into visual graphs (Revenue over time, top-selling products, employee performance metrics).
  • Projects Module: Task tracking, timelines, and milestone management for service-based businesses.
  • Law Firm Module: Bespoke capabilities for legal practices, managing case files, hearing dates, and client documentation.
  • AI Assistant Module: Integrated for dynamic business insights.

Stage 4: Platform Stabilization, SEO & UI Polish

Completed

Focused on heavily solidifying the codebase, preventing crashes during data loads, refining the UI, and ensuring the platform is discoverable by search engines.

Stability & UI Adjustments

  • Global Array Safety Sweep: Replaced vulnerable .map() and .filter() functions globally with safety fallbacks like (array || []).filter(...). This definitively prevents the application from crashing when Firebase hasn't finished loading data.
  • Vite Chunk Load Error Boundary: Added a global error boundary to App.jsx that automatically detects Vite dynamic import failures (which happen when a PWA updates or loses connection) and forces a hard browser reload instead of showing a blank screen.
  • Brand Polish & Footers: Injected a uniform footer across all public views highlighting the WhatsApp Support Number (`+2348124580183`) and a "Developed by Ronimation Studios" credit. Padding and text scales were precisely adjusted for visual hierarchy.
  • Dedicated 'About' Page: Separated the "Features" section from the Registration form. The "About Platform" navigation tab now leads to a clean, distraction-free page.

SEO (Search Engine Optimization)

Hardware Integration Guide

1. Printing Capabilities

The system generates standard A4 PDFs for Invoices/LPOs, and 80mm condensed PDFs for the POS. Required hardware:

  • 80mm Thermal Receipt Printer (USB/Bluetooth) - e.g., Xprinter.
  • Standard Office Printer (For Invoices/LPOs).

2. Payment Terminals

Based on the checkout flow you choose:

  • Standard Setup: Regular Bank POS (Moniepoint, Opay). Cashier uses "Complete Sale (Manual)".
  • Advanced Setup: Smart POS (Paystack/Square). Uses the "Sync Smart Terminal" feature to push prices to the machine automatically over WiFi.
